# CodeSentinel data directory

```
data/
├── raw/          <- PUT THE PRIMEVUL FILES HERE (read-only, never modified)
├── processed/    <- generated by preprocess_primevul
├── chunked/      <- generated by chunk_dataset
└── checkpoints/  <- generated by training.train
```

Everything except this file is git-ignored: datasets and checkpoints are far
too large to commit.

## Required files

The ML pipeline expects these three files, which you must supply yourself:

```
data/raw/primevul_train.jsonl
data/raw/primevul_valid.jsonl
data/raw/primevul_test.jsonl
```

They are **not** in the repository, and the pipeline does not download them.

Once they are in place, confirm the pipeline can read them:

```bash
python -m backend.ml.preprocessing.inspect_dataset
python -m backend.ml.preprocessing.validate_dataset
```

`inspect_dataset` auto-detects the code and label field names, so a PrimeVul
export that uses different column names still works — it prints which fields
it found.

If you keep the datasets somewhere else, point the pipeline at them instead of
copying:

```bash
export CODESENTINEL_RAW_DIR=/path/to/primevul     # or CODESENTINEL_DATA_DIR
```

See `backend/ml/README.md` for the full pipeline documentation.
